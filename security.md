# Security

## Secrets policy

This project uses ESPN session cookies (`SWID`, `espn_s2`) to read your private fantasy league. These cookies authenticate as **you** to ESPN — anyone holding them can read your leagues and act on your behalf.

**Rules:**

- Cookies live in a local `.env` file. `.env` is gitignored.
- Never log, print, or include cookie values in commits, issues, screenshots, or tool output.
- The pipeline runs **locally on your machine only** — there are no GitHub Actions secrets for ESPN cookies. The static site that GitHub Pages serves is built from already-public-to-your-league data (team names, public stats, public transactions).
- Rotate cookies if they ever leak: sign out of ESPN, sign back in, repeat the copy step from `.env.example`.

## Pre-commit guard

Two protections, installed together via `bash scripts/install_hooks.sh`:

1. **`pipeline/_secret_scan.py`** — scans the staged diff for cookie shapes (URL-encoded espn_s2 blobs, SWID-style UUIDs in braces, `ESPN_SWID=` / `ESPN_S2=` env lines). Exits non-zero on any match; the commit aborts. False positives can be silenced by adding the file to `ALLOWLIST_PATHS`.
2. **`pytest`** — runs the suite, blocking commits that break tests. Adds <1s today.

The hook lives at `.git/hooks/pre-commit` and is regenerated by `scripts/install_hooks.sh` (idempotent). The hook is **not** committed to the repo — git doesn't version `.git/hooks/` — so each clone has to run the install script once. Document this in onboarding.

Bypass (`git commit --no-verify`) is explicitly forbidden by [CLAUDE.md](CLAUDE.md). If a hook blocks something it shouldn't, fix the underlying issue or extend `ALLOWLIST_PATHS` — never skip.
